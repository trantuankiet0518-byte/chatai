# Gemini Project Bootstrap

Read these files in order:

1. `AI_HARNESS.md`
2. `.ai/project-context.md`
3. `.ai/current-focus.md`
4. `.ai/handoff.md`

Then run:

```bash
node scripts/ai-context.mjs
```

For parallel work:

- claim a scope in `.ai/current-focus.md`
- use a task file under `.ai/tasks/`
- update `.ai/handoff.md` before finishing
