# Shared AI Memory

Purpose:

- reduce repeated repo scanning
- keep multiple agents aligned
- support session handoff across tools

Files:

- `project-context.md`: stable project summary
- `current-focus.md`: active workstreams and ownership
- `handoff.md`: latest session handoff
- `decision-log.md`: durable technical decisions

Maintenance:

- update only the file that actually changed
- keep entries short
- prefer replacing stale notes over growing long histories
